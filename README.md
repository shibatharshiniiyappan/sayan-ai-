# 🤖 Sayan AI

Sayan AI is an AI-powered document understanding assistant built with Flask, Firebase Authentication, Firestore, and Google's Gemini API.

## Features

- 🔐 User authentication with Firebase
- 📄 PDF document upload
- 🤖 AI-powered document analysis
- 💬 Ask questions about uploaded documents
- ☁️ Firestore storage for user interactions

## Tech Stack

- Python (Flask)
- Firebase Authentication
- Cloud Firestore
- Gemini API
- HTML, CSS, JavaScript

## Project Structure

```
backend/
    app.py
frontend/
    index.html
```

## How to Run

1. Clone the repository.
2. Create a `.env` file and add your Gemini API key.
3. Add your Firebase service account JSON file.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Start the Flask server:

```bash
python backend/app.py
```

6. Open the frontend in your browser.
